# חידון חי 🎉

אפליקציית חידון אינטראקטיבי בסגנון Kahoot, בזמן אמת, מבוססת React + Firebase.

## מבנה המערכת

שלושה מסכים:

- **`/#/admin`** — ניהול חידונים: יצירת שאלות עם תמונה, 4 תשובות, סימון תשובה נכונה. מוגן בסיסמה.
- **`/#/present`** — מסך המנחה (למצגת/מסך גדול): בחירת חידון, הרצת המשחק, QR + קוד הצטרפות, טיימר, גרף תשובות בזמן אמת, חשיפת תשובה נכונה, לוח תוצאות סופי. מוגן בסיסמה.
- **`/#/play`** — מסך השחקנים (טלפונים): הצטרפות עם שם ואבטר/סלפי, ואז 4 כפתורי תשובה בלבד (בלי טקסט/תמונה — אלה מוצגים רק במצגת, כמו ב-Kahoot האמיתי).

## הרצה מקומית

```bash
npm install
npm run dev
```

האפליקציה תרוץ בכתובת שמוצגת בטרמינל (בד"כ `http://localhost:5173`).

## סיסמת מנהל/מנחה

הסיסמה כרגע: **`quiz2026`**

אפשר לשנות אותה בקובץ `.env`, במשתנה `VITE_ADMIN_PASSWORD`.

## איך מריצים חידון באירוע

1. היכנסו ל-`/#/admin` וצרו חידון (שם, שאלות, תמונות, תשובות).
2. פתחו את `/#/present` על המחשב שמחובר למקרן/מסך הגדול. בחרו את החידון ולחצו **Start Game**.
3. יופיע QR code + קוד בן 6 ספרות — האורחים סורקים או מזינים את הקוד ב-`/#/play`.
4. כשכולם הצטרפו, לחצו **▶ התחלת משחק**.
5. לכל שאלה: טיימר רץ אוטומטית, גרף התשובות מתעדכן בזמן אמת. אפשר לסיים שאלה מוקדם, ולהציג/להסתיר "מי בחר מה".
6. בסיום הזמן — חשיפת התשובה הנכונה, ואז מעבר לשאלה הבאה או לתוצאות הסופיות (פודיום 🥇🥈🥉).

## פריסה לאינטרנט (מומלץ: Firebase Hosting)

כדי שהאורחים יוכלו להתחבר מהטלפון שלהם דרך האינטרנט (לא רק Wi-Fi מקומי), יש להעלות את הבנייה (build) לאחסון. הכי פשוט להשתמש ב-Firebase Hosting, כי הפרויקט כבר שם:

```bash
npm install -g firebase-tools
firebase login
firebase init hosting
# בחרו את הפרויקט quiz-live-9f18c
# Public directory: dist
# Configure as single-page app: Yes
# לא לדרוס קבצים קיימים

npm run build
firebase deploy --only hosting
```

בסיום תקבלו כתובת ציבורית (למשל `https://quiz-live-9f18c.web.app`) — זו הכתובת שצריך לפתוח במחשב המנחה ביום האירוע, וה-QR code ייווצר אוטומטית מולה.

## הערות אבטחה

- כללי ה-Database וה-Storage פתוחים לקריאה/כתיבה (`database.rules.json`, `storage.rules`) — מספיק לאירוע פרטי חד-פעמי, לא מתאים לשימוש ציבורי/מסחרי.
- הגנת הסיסמה על Admin/Presenter היא ברמת הממשק בלבד (לא אימות אמיתי) — מספיקה כדי למנוע הפרעה מקרית מאורחים.
- כדאי להעתיק את התוכן של `database.rules.json` ו-`storage.rules` לתוך הכללים בפועל ב-Firebase Console (Realtime Database → Rules, Storage → Rules) כדי שיישארו בתוקף אחרי 30 יום (מצב הבדיקה/Test mode פג תוקף).

## ניקוד

ניקוד בסגנון Kahoot: תשובה נכונה = 500-1000 נקודות לפי מהירות התגובה, בתוספת בונוס רצף (streak) של עד 200 נקודות.
